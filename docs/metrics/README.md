# Metrics

Sill's metrics system lives inside the evidence system, deliberately —
numbers and the events that explain them belong together, and one truthful
system beats two drifting ones.

- **What is tracked and the rules for using numbers:**
  [docs/evidence/METRICS.md](../evidence/METRICS.md)
- **Point-in-time snapshots:** [docs/evidence/snapshots/](../evidence/snapshots/)
  (founding baseline: [2026-08.md](../evidence/snapshots/2026-08.md))
- **Calibration rules for adoption language:**
  [docs/evidence/ADOPTION.md](../evidence/ADOPTION.md)

No parallel analytics infrastructure is planned; the GitHub API is the
machine-readable source, snapshots are the honest record.
