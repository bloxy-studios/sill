# Rust Foundation Maintainers Fund

Status: CURRENT — fund established, process still being defined (Last verified: 2026-08-21)

## Program

Announced 2025-11-04, the Rust Foundation Maintainers Fund (RFMF) collects sponsorships and directs them to people who maintain the Rust language and toolchain. Governance is shared between the Rust Foundation and a Rust Project Funding Team appointed via the Leadership Council. RFC 3931 defines the relationship and proposes a "Maintainer in Residence" (MiR) program alongside project grants and program management.

## Official URL

https://rustfoundation.org/project-support/ (also https://rust-lang.org/funding/ and RFC 3931 at https://rust-lang.github.io/rfcs/3931-rfmf-rust-foundation-maintainer-fund.html)

## What it funds

Maintenance of the Rust Project itself: reviews, mentorship, unblocking, long-term technical work on the Rust codebase. Funds are restricted to programs that pay Rust maintainers to do maintenance work. It does not fund third-party applications written in Rust.

## Eligibility

Maintainer in Residence applicants do not have to already be members of a Rust team, but per RFC 3931 the relevant team must be willing to grant them membership, so in practice applicants should be experienced contributors to the Rust Project itself. Selection looks for technical depth in the relevant area, community standing and trust within the Project, and a track record of sustained maintenance-oriented work.

## Typical funding

UNKNOWN. RFC 3931 states the compensation rate will be published as part of each open call for applications. No figures were published on the pages reviewed. The Foundation's own announcement says "Further details about funding processes, eligibility, and timelines will be shared as the work progresses."

## Application requirements

When funding is available, the Funding Team and Foundation issue an open call for applications; the Funding Team may also proactively invite candidates. Applications are reviewed jointly and the Foundation extends offers.

## Sill fit

NOT ELIGIBLE. This is the single most common misreading of Rust funding: the Rust Foundation funds the Rust Project, not projects that happen to be written in Rust. Sill being a Tauri/Rust application creates zero eligibility here. The only route in is for the maintainer personally to become a recognised Rust Project contributor, which is a separate career decision unrelated to Sill.

## Deadline

No standing deadline. Open calls will be announced when funding is available.
