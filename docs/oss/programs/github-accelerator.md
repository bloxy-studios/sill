# GitHub Accelerator

Status: UNKNOWN — likely dormant/discontinued (Last verified: 2026-08-21)

## Program

A 10-week virtual cohort program that gave open source maintainers non-dilutive funding, mentorship and visibility. Ran in 2023 and 2024; the 2024 theme was open source AI. As of 2026-08-21 the official page still reads "GitHub Accelerator 2024" with a closed 2024 deadline, and no 2025 or 2026 cohort is announced anywhere on GitHub's own properties.

## Official URL

https://github.com/open-source/accelerator (also served at https://accelerator.github.com/)

## What it funds

Historically: full-time maintainer work for 10 weeks on an open source project, with an AI/ML and AI-infrastructure theme in the 2024 round.

## Eligibility

Historic 2024 criteria, retained here only as a reference point: current contributor or maintainer of an open source project on GitHub; team of up to 3; 18+; located in a GitHub Sponsors supported region; not a GitHub/Microsoft employee; clear OSI license; "open source first project with demonstrated community traction and adoption"; clear governance structure; deep focus in AI/ML/AI infrastructure; ability to work full-time 40 hours/week for the duration.

## Typical funding

Historic: $40,000 per project non-dilutive, 10 projects selected, plus a year of Copilot and Azure AI credits. Do not treat these figures as current — there is no current round.

## Application requirements

No open application. The GitHub Secure Open Source Fund FAQ describes Accelerator as a past "experiment" whose results GitHub built on when launching the Secure Fund, which is the strongest available signal that the Secure Fund is the de facto successor.

## Sill fit

NOT ELIGIBLE (no open round). Even if it returned, the historic bar — demonstrated community traction and adoption, plus a 40 hour/week commitment — is exactly what a pre-alpha solo project cannot show. Note also that the separate "GitHub Fund" referenced on the same page is a venture vehicle with M12 and is equity investment, not a grant.

## Missing evidence

- Not applicable while the program is dormant.
- If it returns: users, adoption metrics, governance structure, and capacity to go full-time for 10 weeks.

## Application strategy

Do not build a plan around this. Treat GitHub Secure Open Source Fund as the live GitHub-run funding path. Re-check the page once a year; if a 2027 cohort is announced, re-evaluate then.

## Deadline

None open. Last known deadline was 2024-03-05.
