# NLnet Foundation (NGI / Open Internet Stack)

Status: SEASONAL — currently closed; next call opens 2026-09-03 (Last verified: 2026-08-21)

## Program

Dutch foundation that runs thematic open calls funding free/libre and open source technology, historically as the grant-distributing partner for the EU's Next Generation Internet (NGI) programme. As of 2026-08-21 the apply page states plainly: "At the moment it is not possible to submit proposals to NLnet Foundation." NLnet is winding down a decade of NGI Zero and transitioning to a new "Open Internet Stack" effort plus other programmes.

## Official URL

https://nlnet.nl/propose/

## What it funds

Concrete, technical work on open source software, hardware and content. Releasing under libre/open licenses and applying open standards where possible are transversal requirements across all funds. Each fund has its own scope; the specific thematic scopes for the September 2026 calls are not yet published.

## Eligibility

- Open to individuals and organizations; the submission form asks for name, organisation and country, and does not on its face exclude non-EU applicants.
- HOWEVER: scope and geographic conditions are set per call, and NGI-lineage funds were EU-financed with corresponding constraints. The maintainer's country is a material factor here and MUST be checked against the call-specific "guide for applicants" once the September 2026 calls publish. Treat non-EU eligibility as UNKNOWN until then.
- Proposals must be in English.
- NLnet has an explicit Generative AI policy: the form requires disclosing whether GenAI was used in writing the proposal, which model, and the unedited prompts and outputs.

## Typical funding

UNKNOWN. The application form asks for a requested amount in Euro but the pages reviewed state no range. Do not assume a figure; read the call-specific guide when it publishes.

## Application requirements

Web form. Abstract explaining the whole project and expected outcomes; prior involvement of the applicant in relevant projects; requested amount with a task-level budget breakdown including explicit rates; other past/present funding sources; comparison with existing or historical efforts; significant technical challenges expected; ecosystem description and engagement plan. Attachments are optional background only — the proposal must be self-contained. Deadlines are hard.

## Sill fit

LOW for the 2026 round; possibly MEDIUM later. NLnet reviewers reward concrete, scoped technical deliverables over product vision, and a fresh scaffold with no working terminal gives nothing to scope against. A future application would need to be framed as a specific technical work package (for example: a documented, reusable session/PTY multiplexing layer, or an open protocol for agent-to-terminal session control) rather than "build a terminal app". Also check whether the new Open Internet Stack theme has any relevance to developer tooling at all — NLnet's historic emphasis is internet/privacy/decentralisation infrastructure, which is not obviously Sill's lane.

## Missing evidence

- Working code that demonstrates the maintainer can deliver.
- A work package definable as discrete tasks with hours and rates.
- An argument for why the output is reusable open infrastructure, not one product's internals.
- Confirmation of the maintainer's country against the call's eligibility rules.

## Application strategy

Do not apply in 2026. Watch nlnet.nl/propose/ from 2026-09-03 to read the actual Open Internet Stack call scope, and file that away for a future round once a technical work package exists. Prepare long answers offline — NLnet recommends this explicitly.

## Deadline

Calls open 2026-09-03; deadline 2026-11-03 at 12:00 CEST. Deadlines are hard.
