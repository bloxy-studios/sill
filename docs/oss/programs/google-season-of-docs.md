# Google Season of Docs

Status: CLOSED — program concluded (Last verified: 2026-08-21)

## Program

Google program that paired open source projects with technical writers to improve documentation, with Google funding the writing work. Google's official page now states: "The Google Season of Docs program has concluded after six great years." Past participant case studies remain published, and Google points to its Open Docs Repo on GitHub for open source documentation resources.

## Official URL

https://developers.google.com/season-of-docs

## What it funds

Historically, grants to open source organizations to hire technical writers to execute a defined documentation project.
