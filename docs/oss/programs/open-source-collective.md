# Open Source Collective (fiscal host on Open Collective)

Status: CURRENT (Last verified: 2026-08-21)

## Program

Open Source Collective (OSC) is a 501(c)(6) US nonprofit (EIN 82-2037583) that acts as a fiscal host for open source projects, giving an unincorporated project a legal and financial home without forming a company. It uses the Open Collective platform for public, real-time budgets. Open Collective is the software; Open Source Collective is one host that runs on it — they are not the same entity and the distinction matters when reading their docs.

## Official URL

https://www.oscollective.org/ (platform: https://opencollective.com/)

## What it funds

Nothing. It is not a grantmaker. It holds and administers money a project raises elsewhere: accounting, taxes, invoices, contracts, employment, expense processing, bank account access, automated 990 filings, grant management, trademark registration and holding, and backend integration with GitHub Sponsors and thanks.dev.

## Eligibility

Open source projects. OSC states it hosts 2,500+ projects (a separate figure on the same site says 3,500+). Application is via "Apply Today" on oscollective.org. Specific acceptance criteria and current fee percentage are not stated on the pages reviewed — UNKNOWN, confirm at application time.

## Typical funding

Not applicable — no funding is granted. OSC charges a fund-holding fee on money it administers; the current rate is UNKNOWN from the pages reviewed.

## Application requirements

Submit the hosting application on the OSC site. Requires a described open source project and agreement to operate finances transparently and publicly.

## Sill fit

LOW right now, MEDIUM later. A fiscal host solves problems Sill does not have: it has no money, no contributors to reimburse, no invoices, and no corporate sponsors demanding a legal counterparty. Opening a Collective with a permanently $0 balance is a public signal of inactivity, which is worse than not having one. Precedent worth noting: Tauri itself is fiscally hosted by OSC.

## Missing evidence

- Actual inbound money, or a specific corporate sponsor that requires invoicing a legal entity.
- Contributors other than the maintainer who need to be paid or reimbursed.
- A reason the maintainer's personal GitHub Sponsors account is insufficient.

## Application strategy

Defer. Use personal GitHub Sponsors until there is either (a) a company that wants to send an invoice-backed payment, or (b) more than one person to pay. At that point apply to OSC and switch the GitHub Sponsors payout to the fiscal host — note that GitHub requires contacting Support to change this after a profile is set up, so decide before setting up if possible.

## Deadline

None — rolling applications.
