# OSS Application Package

Reusable, factual source material for open-source program applications
(grants, sponsorship platforms, accelerators, mentoring programs). Nothing
here is tailored to one program; nothing here may exceed what the
[evidence base](../evidence/) supports.

**Standing caveat, written 2026-08-21:** Sill is pre-alpha. The researched
conclusion in [PROGRAM_MATRIX.md](PROGRAM_MATRIX.md) is that **no competitive
application should be submitted yet** — every credible program gates on
evidence Sill doesn't have. This package exists so that when the evidence
exists, applications are assembly, not archaeology.

## Rules for using this package

1. Before ANY application: run the update process in
   [APPLICATION_CHECKLIST.md](APPLICATION_CHECKLIST.md) — stale claims are
   worse than no application.
2. Every claim must trace to [../evidence/](../evidence/) or the repository
   itself.
3. Program facts (deadlines, eligibility) re-verified against official
   sources on application day; the research here carries "last verified"
   dates for a reason.
