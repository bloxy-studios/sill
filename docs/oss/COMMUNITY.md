# Community (Application Summary)

_Current, verifiable state as of 2026-08-21 — updated before any application._

**Community size: 1** (the maintainer). Zero external contributors, zero
discussions, repository created 2026-08-21. No other number would be true.

## What exists instead of a community (deliberately, first)

The complete on-ramp a community needs, built before asking anyone to show
up: contribution guide + 30-minute quickstart, one-command setup/check
scripts, issue forms, labeled newcomer pathway (`good first issue` /
`help wanted` policy), documented triage and review processes with stated
response norms, code of conduct (Contributor Covenant 3.0) with a working
report path, and a contributor ladder with explicit promises per rung
([../COMMUNITY.md](../COMMUNITY.md)).

## Growth approach

Organic and work-anchored: real starter issues (never manufactured), fast
credited review, design-in-the-open (Discussions/RFCs), release announcements
when there is something to announce. No star-farming, no engagement
theatrics, no paid community metrics — the evidence rules
([../evidence/README.md](../evidence/README.md)) prohibit presenting any of
that as traction.

## Measurement

First-time contributors, retention, time-to-first-review, discussion
participation — recorded in [../evidence/snapshots/](../evidence/snapshots/)
from the founding zero-baseline (2026-08). Applications cite those snapshots,
not impressions.
