# Funding Readiness

_What a funder would find if they looked today, category by category — and
what evidence is missing. Companion to
[oss/PROGRAM_READINESS.md](oss/PROGRAM_READINESS.md) (program-facing) and
[oss/EVIDENCE_PACKET.md](oss/EVIDENCE_PACKET.md) (evidence index). Assessed
2026-08-21._

| Category                  | Exists today                                                     | Missing                                                           |
| ------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| Technical maturity        | Scaffold + CI + designs                                          | **The product.** Phase 1 terminal, benchmarks. The blocking gap.  |
| Community maturity        | Full contributor infrastructure                                  | Any contributor besides the maintainer                            |
| Governance                | Documented, honest, maintainer-led                               | Multi-maintainer reality (bus factor 1)                           |
| Documentation             | Comprehensive (architecture, designs, ADRs, processes)           | User docs (nothing to use yet); docs site (deliberately deferred) |
| Security                  | Policy, threat model, scanning, pinned CI                        | Track record; Scorecard history; signed releases                  |
| Reproducibility           | Pinned toolchains, lockfiles, bootstrap script, CI parity        | Reproducible _builds_ (untested, unclaimed)                       |
| Release infrastructure    | Defined + CI-validated pipeline w/ checksums                     | Any actual release                                                |
| Sustainability            | Written plans; scope discipline; knowledge externalized          | Money, second maintainer                                          |
| Public roadmap            | Phased, non-goals versioned, change-controlled                   | Delivery history against it                                       |
| Maintainer activity       | Day-zero burst                                                   | The thing funders actually check: **months of sustained cadence** |
| Contributor accessibility | Quickstart ≤30min, one-command setup/check, starter-issue policy | Proof (a stranger successfully onboarding)                        |
| Impact                    | Calibrated hypotheses ([oss/IMPACT.md](oss/IMPACT.md))           | Any realized impact                                               |
| Adoption evidence         | Founding zero-baseline snapshot                                  | Users, downloads, integrations                                    |
| Funding model             | Policy + plan + researched program matrix                        | Active rail (Sponsors — pending region check)                     |

## Reading

The pattern is uniform and intentional: **infrastructure READY, evidence
EMPTY.** Sill is funding-_structured_, not funding-_ready_. The readiness
plan is therefore not more documents — it is: ship Phase 1, release, snapshot
monthly, onboard first contributors, set up Sponsors after the region check.
Re-assess this file when those change it.
