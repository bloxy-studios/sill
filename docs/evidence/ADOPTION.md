# Adoption Evidence

Objectively measurable adoption signals only: release download counts,
package-manager installs (if Sill is ever packaged), verifiable third-party
integrations, and documented real-world usage.

Calibration rules (binding):

- Downloads ≠ installs ≠ active users. Each term is used only for what was
  actually measured.
- Stars/forks are interest signals and live in metrics snapshots, not here.
- Anecdotes ("someone said they use it") may be quoted with a link, labeled
  anecdote, never aggregated into a number.

## Entries

_None. Sill has no releases, so adoption is zero by definition. This file
stays empty until there is something real to record — an empty file that
tells the truth beats a full one that doesn't._
