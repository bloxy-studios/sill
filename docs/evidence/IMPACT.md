# Impact: Claims ↔ Evidence

The discipline file: every externally-usable claim about Sill maps to
evidence, and claims stronger than their evidence get weakened here first.
Reviewers of funding applications read claims adversarially — this file is
written for that reader.

| Claim (usable externally)                                                                                                  | Evidence                     | Strength                                                               |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------- |
| "Sill is an open-source (MIT OR Apache-2.0) terminal project with public governance, security policy, and CI from day one" | This repository; founding PR | PUBLIC — usable now                                                    |
| "Sill has a documented, provider-neutral design for agent-era terminal workflows"                                          | docs/design/, ADR-0007       | PUBLIC — design intent only; must be labeled as design, not capability |
| Anything about users, adoption, performance, or working software                                                           | —                            | NO EVIDENCE — not usable. Do not say it.                               |

## Currently unsupportable claims (kept visible on purpose)

"Sill improves developer productivity", "developers use Sill with coding
agents", "Sill is fast/lightweight" — all unsupported until benchmarks and
real usage exist. The roadmap describes intent; intent is stated as intent.
