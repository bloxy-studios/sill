# Evidence Log

Chronological record of significant, verifiable project evidence. Format and
rules: [README.md](README.md). Entries are appended, never edited into a
better story; corrections get their own entries.

## Entry format

```
Date:                YYYY-MM-DD
Category:            Technical | Community | Adoption | Ecosystem | Security | Performance | Health | Funding
Event:               one line
Evidence:            the artifact (PR #, release tag, advisory id, result file)
Source:              where it lives
What it demonstrates: one line, no stretching
Verification:        UNVERIFIED | INTERNAL | PUBLIC | THIRD-PARTY VERIFIED
Notes:               optional
```
