# Getting Help

Sill is a pre-alpha project maintained by one person. Support is best-effort,
but every report and question is read.

## Where to go

| I want to…                         | Go to                                                                                              |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| Report a bug                       | [GitHub Issues](https://github.com/bloxy-studios/sill/issues/new/choose) (use the Bug Report form) |
| Report a security vulnerability    | **Not issues.** See [SECURITY.md](SECURITY.md)                                                     |
| Propose a feature                  | GitHub Issues (Feature Request form) — large ideas start in Discussions                            |
| Ask a question                     | [GitHub Discussions → Q&A](https://github.com/bloxy-studios/sill/discussions)                      |
| Discuss development / architecture | GitHub Discussions → Development                                                                   |
| Contribute                         | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                 |

## Ground rules

- Issues are for actionable, reproducible problems and concrete proposals.
  General questions belong in Discussions so issues stay a working queue.
- Please search existing issues and discussions before opening a new one.
- There is no SLA. See [GOVERNANCE.md](GOVERNANCE.md) for how the project is
  currently run.

## What not to expect (yet)

Sill is not yet functional software. There are no installation packages, no
releases, and no user-level support. If you are here this early: the most
useful thing you can do is read the [roadmap](ROADMAP.md) and join design
discussions.
