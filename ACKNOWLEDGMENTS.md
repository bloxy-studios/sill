# Acknowledgments

Sill stands on other people's open source. The projects below are actual
dependencies or direct influences today — this list is kept honest and grows
only as real usage grows. Full dependency license inventory:
[docs/THIRD_PARTY.md](docs/THIRD_PARTY.md).

## Built with

- [Tauri](https://tauri.app) (MIT/Apache-2.0) — application shell, IPC, packaging
- [Rust](https://www.rust-lang.org) and its crate ecosystem (see `src-tauri/Cargo.lock`)
- [React](https://react.dev) (MIT) — UI
- [Vite](https://vite.dev) (MIT) — frontend build tooling
- [TypeScript](https://www.typescriptlang.org) (Apache-2.0)
- [Bun](https://bun.sh) (MIT) — JavaScript runtime/package manager for development

## Influences

The terminal space has decades of prior art. Sill learns from — and does not
claim affiliation with — projects including xterm, tmux, iTerm2, Alacritty,
kitty, WezTerm, Zellij, and Ghostty. See
[docs/COMPETITIVE_LANDSCAPE.md](docs/COMPETITIVE_LANDSCAPE.md) for an honest
comparison.

"Built with" and "compatible with" statements in this repository describe
technical facts, not partnerships or endorsements.
